# 06 データ設計

## 1. 方針

Minecraft通信の本文はDBへ保存しない。DBには認証、ルーム管理、監査に必要な最小限のメタデータだけを保存する。

## 2. サーバー側テーブル

### rooms

| カラム | 型 | 制約 | 説明 |
|---|---|---|---|
| id | uuid | PK | ルームID |
| join_code_hash | varchar(128) | UNIQUE | 参加コードのハッシュ |
| host_client_id | uuid | NOT NULL | ホストクライアント |
| edition | varchar(16) | NOT NULL | java / bedrock |
| max_guests | smallint | NOT NULL | 最大人数 |
| approval_mode | varchar(16) | NOT NULL | automatic / manual |
| relay_region | varchar(32) | NOT NULL | Relay地域 |
| status | varchar(16) | NOT NULL | active / closed / expired |
| expires_at | timestamptz | NOT NULL | 有効期限 |
| created_at | timestamptz | NOT NULL | 作成日時 |
| closed_at | timestamptz | NULL | 終了日時 |

### room_members

| カラム | 型 | 制約 | 説明 |
|---|---|---|---|
| id | uuid | PK | メンバーID |
| room_id | uuid | FK | ルームID |
| role | varchar(16) | NOT NULL | host / guest |
| display_name | varchar(32) | NOT NULL | 表示名 |
| connected_at | timestamptz | NULL | 接続日時 |
| disconnected_at | timestamptz | NULL | 切断日時 |
| disconnect_reason | varchar(64) | NULL | 切断理由 |

### relay_sessions

| カラム | 型 | 制約 | 説明 |
|---|---|---|---|
| id | uuid | PK | セッションID |
| room_id | uuid | FK | ルームID |
| guest_member_id | uuid | FK | ゲストID |
| bytes_up | bigint | NOT NULL | 上り転送量 |
| bytes_down | bigint | NOT NULL | 下り転送量 |
| started_at | timestamptz | NOT NULL | 開始日時 |
| ended_at | timestamptz | NULL | 終了日時 |

## 3. ローカル設定

保存先案：`%LocalAppData%\MineLink\settings.json`

```json
{
  "schemaVersion": 1,
  "displayName": "Masakun",
  "theme": "system",
  "language": "ja-JP",
  "minecraft": {
    "edition": "java",
    "hostAddress": "127.0.0.1",
    "hostPort": 25565,
    "guestListenPort": 25565
  },
  "startup": {
    "minimizeToTray": true,
    "launchAtLogin": false
  }
}
```

アクセストークン等はJSONへ平文保存せず、Windows Credential LockerまたはDPAPIを利用する。

## 4. ログ

| 種類 | 保存先 | 保持 |
|---|---|---|
| UIログ | アプリ内メモリ | 起動中のみ |
| 診断ログ | `%LocalAppData%\MineLink\Logs` | 7日または100MB |
| Relay監査ログ | サーバー側ログ基盤 | 30日を初期案 |

ログへ参加コード、トークン、IPアドレス全文、Minecraftパケット本文を出力しない。IPが調査に必要な場合は短期保持とマスキングを適用する。
