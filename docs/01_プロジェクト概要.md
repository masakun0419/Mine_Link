# 01 プロジェクト概要

## 1. 背景

一般的な自宅Minecraftサーバーをインターネットへ公開するには、ルーターのポート転送、Windows Firewall、固定IPまたはDDNSなどの設定が必要になる。利用環境によってはCGNATなどにより、利用者自身でポートを開放できない場合もある。

Hamachi等の仮想LAN製品を利用する方法はあるが、Minecraft以外のネットワークにも影響する可能性があり、利用者にとって設定項目が多い。

## 2. 解決方針

MineLinkは以下を基本方針とする。

- Minecraft通信だけを転送する。
- ホスト・ゲストともに外向き接続を使用する。
- 参加コードでルームへ参加できる。
- 接続先を`localhost`として利用できる。
- ネットワーク知識がなくてもGUIから操作できる。
- 通信をTLSで暗号化する。

## 3. 対象範囲

### 3.1 初版に含む

- Windowsデスクトップクライアント
- Minecraft Java EditionのTCP転送
- ルーム作成・参加・退出
- 参加コードの発行
- 接続者一覧
- Ping、通信状態、転送量の表示
- 外部中継サーバー
- ローカルログと障害調査用ログ

### 3.2 初版に含まない

- PC全体の仮想LAN化
- 独自VPNドライバー
- Minecraftサーバー本体のホスティング
- Minecraftアカウント認証の代行
- MODやプラグインの自動導入
- DDoS攻撃を完全に防止する保証
- macOS、Linux、スマートフォン対応

## 4. 利用者

| 利用者 | 役割 |
|---|---|
| ホスト | 自分のPCでMinecraft Serverを起動し、ルームを公開する |
| ゲスト | 参加コードを入力し、ホストのサーバーへ接続する |
| 運用管理者 | 中継サーバー、障害、バージョン、利用状況を管理する |

## 5. 用語

| 用語 | 意味 |
|---|---|
| ルーム | 1台のMinecraft Serverと複数ゲストを紐づける単位 |
| 参加コード | ルーム参加に使用する短時間有効なコード |
| 制御チャネル | ルーム操作や状態通知に使用する通信 |
| データチャネル | MinecraftのTCPデータを転送する通信 |
| Relay | ホストとゲストの通信を仲介する外部サーバー |
