## 2. 目的

MineLinkは、ルーターのポート開放を行わずに、離れたユーザー同士でMinecraftマルチプレイを利用できるようにするWindowsアプリケーションである。

ホストとゲストが外部の中継サーバーへ接続し、Minecraft通信だけを暗号化して転送する。PC全体を仮想LANへ参加させるのではなく、対象ポートだけを扱うことで、導入と操作を簡単にする。

## 4. 初版の前提

- Windows 10/11を対象とする。
- Minecraft Java Editionを最初の対象とする。
- ホストPCではMinecraft Serverが`127.0.0.1:25565`で起動しているものとする。
- ゲストはMineLinkが開くローカルポートへMinecraftから接続する。
- 中継サーバーはグローバルIPを持つVPSへ配置する。
- 初版では1ルーム最大10接続を目安とする。
- ユーザー登録なしでも試せるゲストモードを用意する。
- 統合版のUDP転送は初版完成後に追加する。
